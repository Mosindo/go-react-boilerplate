# Archived SaaS demo code

Everything here belonged to the previous generic SaaS boilerplate (billing with Stripe,
posts, comments, organizations, tenant users, old chat/notifications/files, PowerShell
smoke scripts, old migrations and tests). It is **not built, tested or deployed**; it was
moved out of `services/api` when the repository became the Lumen dating app, so nothing
was lost but nothing can accidentally ship.

Safe to delete once you no longer need it as a reference: `git rm -r archive/`.
Git history keeps it either way.
